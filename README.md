# 企业专利统计看板（单机版）

当前项目只保留本机版专利看板，不再包含 Cloudflare、D1、Drizzle、外部数据库或云端部署代码。

## 直接使用

打开 `outputs/单机版专利看板/企业专利统计看板.exe`。程序仅监听 `127.0.0.1`，数据保存在 EXE 同目录的 `data/patents.db`。

## 功能

- 包含完整案件字段的 Excel 模板下载、批量导入和批量导出；费用汇总按一个专利一行，并兼容旧“缴费台账”和既有“专利家族/费用”格式
- 专利字段手动增删改查
- 专利族、月度/季度/年度统计
- 缴费台账和临期提醒
- 企业微信群机器人测试消息及每日定时推送

## 源码

单机版源码位于 `tools/local_patent_dashboard`。运行 `local_dashboard.py` 可直接启动；需要重新生成 EXE 时使用同目录的 PyInstaller spec 文件。

专利 PDF 由用户自行保管，本项目不会删除外部 PDF 文件。
